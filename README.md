# 🎵 Music Player

A modern and responsive **Music Player** built using **HTML, CSS, and JavaScript**. This project provides a simple and interactive interface for playing music while demonstrating core front-end development concepts.

## ✨ Features

- Clean and modern user interface
- Responsive design for desktop and mobile devices
- Play and Pause functionality
- Next and Previous track controls
- Music progress bar
- Song duration and current time display
- Album cover image for each song
- Song title and artist information
- Smooth transitions and hover effects
- Playlist support with multiple songs
- Interactive music controls
- Easy-to-use layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
